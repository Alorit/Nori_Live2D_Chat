# Nori Live2D Agent

住在桌面上的 AI 伙伴。DeepSeek 驱动的大脑 + 会动的 Live2D 身体 + 自己的作息和情绪。

**你不理她，她也在过日子。**

## 她能做什么

### 自己活着

大多数桌宠只有两件事：跟着鼠标转眼睛、等你去戳。Nori 从 v0.3.0 开始有了一套自己的日常：

- **没人陪也会动**：东张西望、伸懒腰、换表情、歪头看你，按一天里的时间段换心情（早上犯困、白天活跃、深夜安静）
- **会犯困**：凌晨 1 点到 7 点自动切换到睡觉姿势，闭眼、不主动搭话
- **知道你在不在**：你离开 5 分钟她去睡，你回来她伸个懒腰——判断只用本地系统 API，不联网、不截图
- **有自己的想法**：聊天窗里会浮出居中的灰色小字 `💭（担心）他今天气压很低，先别吵他。`，那是她当班时想到的东西，不会打断你的对话
- **有打扰预算**：每小时最多主动开口 3 次，两句至少隔 45 秒，你一打字她就把没说完的台词收回去

代价控制得很死：身体动作是本地规则，**0 token**；动脑子平均 5~30 分钟一次，实测一次唤醒 **853 输入 / 153 输出**。

### 记得你

不是把聊天记录堆进上下文就算记忆。

- **分类型存**：你的偏好和基本信息、发生过的重要事件、她学到的相处规则，分开存放、分开检索
- **按人格隔离**：换人格等于换一段人生，记忆和会话互不污染
- **会忘**：重要性打分 + 时间衰减 + 容量上限，最不重要最旧的先走
- **会反思**：每若干轮后台自我复盘，从对话里提炼「主人不喜欢什么」这类东西，写成长期规则
- **看反馈**：👍👎 会真的调整对应记忆的权重，不是装饰
- **定时回顾**：定期让 LLM 把相似的记忆合并成一条，避免记成一锅粥

### 看得见、查得到、知道现在几点

- **发图给她**：截图、照片直接拖进聊天窗，她通过视觉 MCP 真的能看图（豆包视觉模型）
- **联网搜索**：`/搜 今天有什么新闻`、`帮我搜 京都天气`
- **时间感**：每轮对话注入当前日期、星期、时间，问「明天几号」不会瞎编

### 会说话

- **Nori 本音**：GPT-SoVITS + Nori 语音样本微调，说中文时是同一个人的声音
- **口型对得上**：TTS 播放状态实时推给 Live2D 驱动嘴型
- **有兜底**：GPT-SoVITS 冷启动那 1 分钟里消息会排队，不想等就切 Windows 自带语音

### 长得好看

Live2D 不是网页嵌进去的 Canvas，而是独立的 .NET 原生窗口（Avalonia + OpenGL）：透明、置顶、可拖动、可缩放、点击穿透。项目里已经内置了编译好的宿主，**不需要装 .NET 运行时**。

模型自带 5 组 12 条动作和 16 个表情，说话时的表情动作是 LLM 在回复里自己挑的，不是随机播动画。

### 一把抓的控制台

所有操作都在一个窗口里，不用改配置文件：

| 页签 | 能干什么 |
|---|---|
| 💬 聊天 | 气泡式对话、发图、发贴图、👍👎、导出训练数据 |
| 🎛 基础设置 | 填 API Key、选模型、调语速和宠物大小、换头像、字体 |
| 🗂 聊天记录 | 按人格组织会话，新建 / 重命名 / 删除 |
| 📜 人格 | 切换、编辑、导入人格（就是一份 `.md`，保存即生效） |
| 🧠 记忆 | 搜索、编辑、删除记忆与规则，手动触发回顾合并 |
| 🔌 MCP / Skills | 导入外部工具和指令包，随时启用停用 |
| 🖥️ 控制台 | 统一日志、后台服务启停 |

## 下载与上手

| 文件 | 大小 | 说明 |
|---|---|---|
| `Live2D_agent_byAlorit_v0.3.0_bata.zip` | 95 MB | 完整项目，**解压即用**（含 Live2D 渲染器） |
| `Nori_TTS_Voice_nori.zip` | 256 MB | GPT-SoVITS 语音模型 + 参考音频，放进 `data/voices/` |

从 [Releases](https://github.com/Alorit/Nori_Live2D_Chat/releases) 下载后三步：

1. 解压，双击 **`run.bat`**（首次会自动建 `.venv`、装依赖，需要几分钟）
2. 在 **⚙ 设置 → 基础设置** 里填自己的 DeepSeek API Key，点「应用并保存」
3. 回聊天页，开始说话

第一次启动时她会先问你「我该怎么称呼你」，之后可以在设置里改；她私下想到你的时候也用这个称呼。

需要看 Python 原生日志时用 `run_console.bat`；只想聊天不想开桌宠用 `run_chat_only.bat`。

**环境要求**：Windows 10/11，Python 3.10+（在 3.14 上测试通过）。

## 想改点什么

| 想做的事 | 在哪改 |
|---|---|
| 换个人格 | 设置 → 📜 人格，直接编辑 `.md`（当前 `.md` 就是完整 System Prompt） |
| 换音色 | `config.yaml` → `tts.gpt_sovits`，填参考音频路径和对应文字 |
| 换模型 | 设置 → 🎛 基础设置 → Live2D 模型，或在 `config.yaml` 改路径 |
| 接入视觉能力 | 先跑 `scripts\start_vision_mcp.bat`，再在 设置 → 🔌 MCP 导入 `vision_mcp/nori-vision.mcp.json` |
| 关掉自主行为 | `config.yaml` → `autonomy.enabled: false`，或在控制台页停掉 Heart |
| 不输出表情动作标签 | 删掉 `config.yaml` 的 `persona.control_rule` |
| 接自己的工具 | 设置 → 🔌 MCP / Skills，支持 HTTP / SSE / stdio 三种传输 |

真实 API Key 不会写进 `config.yaml`，统一落在 `data/settings_overrides.json` 或环境变量里。

## 工作方式

```
你说话 / 她自己醒来
      │
      ▼
取最近对话 + 检索长期记忆 + 行为规则 + 当前时间
      │
      ▼
DeepSeek 生成回复（顺带输出 [expr:...] / [motion:...] 标签）
      │
      ├─▶ 标签 ──▶ 驱动 Live2D 表情动作
      ├─▶ 文本 ──▶ 聊天窗 + TTS 朗读 + 口型同步
      ▼
按重要性决定要不要写进长期记忆
      │
      ▼
定期反思：提炼偏好 / 事件 / 相处规则，合并相似记忆
```

自主性单独一条线，三层各管各的频率：

| 层 | 在做什么 | 多久一次 | 花 token 吗 |
|---|---|---|---|
| 反射层 | 微动作、作息、抢占、说话预算 | 1 秒 | 不花 |
| 心智层 | 决定接下来几分钟做什么、说什么 | 5~30 分钟 | 约 1k |
| 感知层 | 你离开多久、在用什么程序 | 2 秒 | 不花 |

## 常见问题

**启动后没有声音？** GPT-SoVITS 冷启动约 1 分钟，就绪后会自动切过去；也可以在 `config.yaml` 把 `tts.backend` 改成 `system` 用 Windows 自带语音。

**表情动作没反应？** 检查 `config.yaml` 的 `emotion_map` / `motion_map` 里填的是不是模型真实的名字，模型里不存在的名字会被静默忽略。

**窗口白底或黑底？** 那是显卡驱动对 OpenGL 透明窗口不友好，更新驱动即可；也可以先关掉 Live2D 用内置宠物。
